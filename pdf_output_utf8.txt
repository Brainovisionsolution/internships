AIGAÔÇ»ÔÇôÔÇ»AI for Generation and Automation
(Internship Program, Updated)
Executive Summary: The AIGA internship is an intensive 12ÔÇweek (90-hour) program preparing B.Tech
students for industry roles in generative AI and automation. It covers AI fundamentals (neural nets,
NLP), advanced topics (transformers, LLMs, small language models), engineering practices (prompt/
context/inference engineering, RAG pipelines), tool usage (Google AI Studio/Gemini, Antigravity, GitHub
Copilot,  etc.),  and  emergent  skills  (agents,  AI  ethics).  Importantly,  the  curriculum  now  includes
dedicated modules on Evaluation & Metrics (e.g. BLEU/ROUGE/BERTScore and LLM-as-judge), 
Cost Awareness (token counting, prompt optimization), Responsible AI (bias, privacy, hallucination
mitigation,  red-teaming),  Data  Engineering  for  RAG (document  chunking,  embedding  strategy
), and Real-Time Streaming (SSE/WebSockets). Students also learn to train a Small Language
Model (SLM) via fine-tuning open-source models. The program balances lectures and hands-on
labs,  with  daily  1.5ÔÇæhour  sessions  (5  days/week)  totaling  ~90ÔÇ»hrs.  Each  day  includes  theory,  coding
exercises, or labs; every week has a capstone or project milestone. Assessment combines labs, quizzes,
and projects evaluated by clear rubrics. Industry partnerships (Google Cloud, IBM, Microsoft)
support cloud credits, guest sessions, and eventual certification opportunities (e.g. Google ML Engineer ,
IBM AI Engineering). Infrastructure requirements (GPU cloud/AI API costs) are budgeted; for example,
renting an A100 GPU costs ~$0.78ÔÇô5.78/hr, and GPT-4-like models ~\$0.03ÔÇô0.06 per 1K tokens input/
output. Outcomes align with B.Tech Program Outcomes (fundamentals, problem analysis, design, tool
usage, teamwork) .
Prerequisite Knowledge
Students should have  strong programming skills (Python), basic understanding of calculus/linear
algebra,  and  prior  coursework  in  introductory  Machine  Learning  (classification,  loss  functions).
Familiarity with Linux, Git, and data handling (Pandas, SQL) is assumed. This aligns with typical B.Tech
curricula and sets the foundation for advanced AI topics.
Program Outcomes Mapping
Completion of AIGA maps to B.Tech program outcomes: 
Engineering Knowledge (PO1): AI/ML theory (neural nets, statistics) and modern tools. 
Problem Analysis (PO2): Framing AI tasks (e.g. RAG chatbot requirements) and diagnosing
model behavior . 
Design/Development (PO3): Designing AI pipelines (transformer models, RAG architecture,
agents) and software components. 
Modern Tool Usage (PO5): Using current AI platforms (Gemini API, Antigravity, Copilot,
HuggingFace) and coding libraries. 
Ethics (PO8) & Society: Addressing AI fairness, bias, privacy, and societal impact in projects. 
Teamwork & Communication (PO9,PO10): Collaborative labs and presentations build these
skills. 
These outcomes are assessed through project deliverables, coding assignments, and presentations,
using rubrics from educational internships.

Syllabus & Learning Objectives
The syllabus covers key topics with moduleÔÇlevel objectives:
Module 1 (Weeks 1ÔÇô2): AI/ML Fundamentals. Introduce artificial neural networks: perceptrons,
activation functions, MLPs, and basic CNN/RNN architectures. Objectives include understanding
backpropagation for training, and implementing simple NNs in PyTorch/TensorFlow. Hands-on:
Build/train an MLP classifier and a CNN on a toy dataset. 
Module 2 (Week 2): NLP Basics. Introduce natural language processing: tokenization, text
preprocessing, and embeddings. Topics: Word2Vec, GloVe, and transformer embeddings (BERT
embeddings). Objectives: process text data, use pre-trained embeddings for classification. 
Hands-on: Train a sentiment classifier; practice tokenizing and embedding text. 
Module 3 (Week 3): Transformer Architectures. Study the Transformer model. Understand
self-attention, multi-head attention, and positional encoding. Illustration: see Figure below
(embedding + Q/K/V process). Objectives: explain how transformers capture context, and
implement an attention layer . Hands-on: Visualize attention weights; code a simple transformer
block. 
Figure:Transformer  Transformer  (Embedding  +  Attention) ÔÇô  Token  embeddings  (with  positional
encodings) feed into multi-head attention. Students build and test these modules.
Module 4 (Week 4): Large vs. Small Language Models. Compare large pretrained LLMs (GPT/
BERT) with SLMs (Small LMs). Objectives: discuss scale, personal/custom LMs, and fine-tuning. 
Case study: Introduction to building a small language model (SLM) ÔÇô e.g. fine-tuning an open
7B model (Phi-2, Mistral, TinyLlama) to a domain/persona. Students will perform LoRA/Q-LoRA
fine-tuning on ~100ÔÇô500 examples. Hands-on: Fine-tune an SLM and generate sample
outputs. 
Module 5 (Weeks 5): Prompt Engineering & Cost Optimization. Learn to craft effective
prompts for LLMs (zero-shot, few-shot, chain-of-thought techniques). Introduce system/user
messages and template design. Cost-awareness: Estimate token usage with tools (OpenAIÔÇÖs
tiktoken) and API pricing. For example, counting tokens with tiktoken helps predict cost.
Objectives: minimize token use by prompt compression without losing quality. Lab: Given a task

Module 6 (Week 6): Context Engineering & Data Prep. Cover RAG pipelines: retriever + LLM.
Focus on data engineering for RAG: document chunking (token-based, page-level, section-level)
 and metadata tagging. Students learn strategies (e.g. 15% overlap chunks) to maximize
retrieval of relevant context. Discuss embedding choice (sentence vs paragraph embeddings)
and index storage. Lab: Build a mini RAG: chunk a set of documents, generate embeddings (e.g.
via Sentence-BERT), and implement a nearest-neighbor retrieval. 
Module 7 (Week 7): Evaluation & Metrics. Teach how to evaluate RAG/chatbot performance.
Topics include automatic metrics: BLEU and ROUGE for n-gram overlap , and BERTScore
for semantic similarity. Discuss limitations (these capture surface overlap but not semantics
). Introduce LLM-as-judge methods (e.g. G-Eval, GPTScore) where an LLM scores answers.
RAG-specific metrics: Contextual Relevancy (how well the retriever fetched useful info), and
Answer Accuracy (agreement with ground truth). Lab: Evaluate outputs from their RAG system
using BLEU/ROUGE and also a semantic scorer . Compare with manual evaluation, and refine
prompt/context based on insights. 
Module 8 (Week 8): Inference Engineering & Streaming. Cover deploying models efficiently:
latency/throughput tradeoffs, quantization, batching, and cache reuse. Include a Streaming
inference lesson: SSE vs WebSocket for token streaming, to improve UX and reduce wait
times. Objectives: implement a streaming API (e.g. OpenAI stream) in code and allow aborting to
save tokens. Lab: Build a small web demo streaming LLM responses (use SSE) and measure time
until first token (TTFT) improvement. 
Module 9 (Week 9): AI Tools for Content & Code. Hands-on use of platforms: Google AI Studio
(Gemini)  for generative text/image/video; GitHub Copilot for coding assistance; and 
Google Antigravity for agentic coding tasks. Lab: Use Gemini API to generate a blog
post and an image. Use Copilot to write a function, then launch Antigravity to create a small
coding agent (e.g. auto-testing). Evaluate each toolÔÇÖs ease-of-use, cost (free tiers vs. paid), and
integration in workflows. 
Module 10 (Week 10): Agentic AI & Automation. Study AI agents that autonomously perform
tasks using LLMs and tools. Components: agent planner (LLM with tools), tool APIs
(search, calculators, custom functions), and multi-step workflows. Discuss frameworks
(LangChain, ReACT). Lab: Build a simple agent (e.g. budget chatbot that uses web search and
calculator tools). Demonstrate it planning and executing a task, then evaluate its Task
Completion (did it achieve the goal). 
Module 11 (Week 11): Responsible AI & Red-Teaming. Deep dive on AI ethics. Topics: Bias and
Fairness (recognizing and mitigating demographic biases), Privacy (avoiding private data leaks
in prompts), Hallucination (false content risks). Introduce Red-Teaming: actively stress-testing
the AI with adversarial prompts to find vulnerabilities. For example, attempt prompt-
injection or toxic queries to test safeguards. Lab: Perform a red-teaming exercise: given an LLM
prompt, iteratively craft inputs to elicit biased or harmful outputs. Record findings and discuss
mitigations (filtering outputs, adding guardrails). 
Module 12 (Week 12): Capstone Projects & Review. Students work in teams on an industry-
style capstone (e.g. a domain-specific RAG chatbot with an agentic front-end). Deliverables: a
functional prototype, code repo, and presentation. This week also includes final reviews,
feedback, and certification guidance.
Reading & Resources: Official docs and key papers supplement the modules (e.g. Vaswani et al. 2017
on Transformers, OpenAI GPT-3 blog, LangChain docs for agents, Google Cloud prompt guide
).  Recommended  hands-on  tutorials  include  Hugging  Face  Transformer  tutorials,  tiktoken  cost
analysis ,  NvidiaÔÇÖs  chunking  blog,  and  the  Antigravity  and  Gemini  official  guides.
Assigned readings are given weekly (and links in resources).

Faculty & Mentorship
Instructors: 1ÔÇô2 faculty coordinating theory sessions. 
Industry Mentors: ~1 mentor per 8ÔÇô10 students for labs and projects (total ~3 mentors for 25
students). Mentors guide project selection, code reviews, and reinforce best practices. 
Roles: Faculty handle lectures, evaluate concept quizzes; mentors supervise labs, grade
assignments, and interact with students daily. 
Student Teams: Each team (4ÔÇô5 students) has an assigned mentor to ensure manageable load
and personalized guidance.

Compute: Provide GPU access (cloud or on-prem). For example, using Google Cloud Vertex AI or

few thousand tokens of paid LLM usage).
Licenses: GitHub Copilot is free for students; otherwise need organizational license ($10/mo
typical). All other tools have free or academic licenses.
Evaluation & Assessment
Daily Labs: Short coding or design exercises are given each day, reinforcing the topic.
Instructors or mentors grade these promptly for feedback. 
Weekly Assignments: Each week has a mini-project or problem set (e.g. ÔÇ£implement a prompt-
ranking systemÔÇ or ÔÇ£write a report on chunking strategyÔÇ) to be submitted by weekÔÇÖs end. These
are graded on correctness and depth. 
Capstone Project: Teams work on a semester-long project with defined milestones (see
schedule). Evaluation rubric includes: functionality, innovation, use of AI techniques, teamwork,
documentation, and presentation quality. For example, rubrics emphasize technical
correctness, quality of solution, report clarity, and team collaboration. 
Quizzes & Exams: Short quizzes may test theory (e.g. writing out BLEU formula, explaining
attention). 
Peer Review: Teams may peer-review other projects (code review, critique) to foster
collaborative learning. 
Metrics-based Evaluation: Student projects using RAG are also evaluated via the metrics taught
(BLEU/ROUGE, LLM-judge) as part of learning the evaluation process.

Day-wise Schedule (5 days/week, 1.5 hr/day, 90 mins each)
Week 1 (9ÔÇ»hrs): AI/ML Foundations
- Day 1:Neural Nets Intro: Perceptron, activation functions. Daily Assignment: Implement a sigmoid
neuron for AND/OR.
- Day 2:Feedforward NN: Multi-layer perceptron; backprop algorithm. Assignment: Hand-trace 2-layer
NN on simple data.
- Day 3:CNN/RNN Basics: Convolution and pooling intuition; simple RNN cell. Lab: Build a 1D CNN for
text classification (Keras).
- Day 4:Lab: Code a small neural net (PyTorch) on MNIST or similar . Weekly Assignment: Write a report on
training curves (loss/accuracy).
-  Day 5:NLP Overview: Tokenization, BoW, TF-IDF.  Quiz: Short quiz on NN terminology;  Assignment:
Preprocess a text corpus.
Week 2 (9ÔÇ»hrs): NLP & Embeddings
- Day 6:Word Embeddings: Word2Vec, GloVe. Lab: Generate 2D plot of word vectors.
- Day 7:Contextual Embeddings: BERT, sentence embeddings. Assignment: Extract BERT embedding for
sample sentences.
-  Day  8:Text  Classification: LSTM/Transformer  for  sentiment  analysis.  Lab: Fine-tune  a  small
transformer (HuggingFace) on a movie review dataset.
-  Day 9:Sequence Tasks: Q&A and translation examples.  Assignment: Evaluate model on custom test
sentences.
- Day 10:Quiz/Discussion: Key NLP concepts; Weekly Assignment: Build and test an NER (named entity
recognition) pipeline.
Week 3 (9ÔÇ»hrs): Transformers & LLM Overview
-  Day  11: Transformer  Architecture: Self-attention,  Q/K/V,  multi-head.  Illustration:
embedding+attention figure above.
-  Day  12:Attention  Demo: Visualize  attention  heads;  explain  their  role  in  context.  Lab: Use  a
